## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Scenario text -> LLM provider | User text (possibly containing real names) leaves the machine to the selected provider |
| LLM output -> EntitySubstitution | Untrusted names/aliases enter the substitution map |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-17 | T (Prompt injection via scenario) | RealEntityDetector prompts | mitigate | Scenario is placed only in UserPrompt (tested), system prompt is a constant; strict schema limits output shape |
| T-02-18 | I (Real names sent to provider) | DetectAsync | accept | Goes only to the user-selected provider (telemetry removed in Phase 1, D-16); required to detect names; nothing is logged to disk |
| T-02-19 | D (Malicious aliases -> regex) | Downstream NameSubstitution | mitigate | Aliases are trimmed strings; NameSubstitution escapes them and uses a timeout (02-02) |
| T-02-20 | D (Denial of wallet) | DetectAsync | mitigate | MaxOutputTokens 4,000; scenario capped at 8,000 chars (02-01); UI re-runs only when the scenario hash changes (02-07) |
| T-02-21 | R (Silent failure lets real names through) | DetectAsync | mitigate | GetValueOrThrow: refusals/failures throw LlmCallException; the step blocks Next and shows the error |

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pool threads → UI thread | Checkpoints and snapshot data cross into WinForms |
| activity row → shell | A file path from journal-derived data is opened with ShellExecute |
| user → destructive action | Start Over deletes generated files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-47 | Elevation | OpenEml ShellExecute | mitigate | Path must pass IsSafeEmlPath and ResolveUnderCase (under the verified case folder) and end in .eml; nothing else is opened (Phase 3 rule) |
| T-05-48 | Tampering | CaseDraft cross-thread mutation | mitigate | All draft changes happen in ApplyCheckpointAsync on the UI thread; workers only touch GenerationSnapshot |
| T-05-49 | Repudiation / data loss | Start Over | mitigate | C-G2 confirm with Warning icon and default No; deletes only validated generated paths (GenerationReset) |
| T-05-50 | Denial of Service | Close during run | mitigate | C-G3 confirm, cancel + bounded wait (10 s) via WaitWhileStopping; journal already holds finished threads |
| T-05-51 | Information Disclosure | Spend during unattended reopen | mitigate | Reopen never starts a run; materialization makes no provider calls |
</threat_model>

<objective>
Implement the W3 data layer: per-exhibit staleness for discovery documents. Store a DocId -> ThreadDone-Utc map for the emails each document cites, expose the current map from the journal replay the corpus detector already performs, and add `StaleSource.Exhibits` to the derived staleness check.

Purpose: SC3 — Start Over and Regenerate Thread mark discovery documents whose cited exhibits changed or were deleted as Out of date. Because staleness is derived (08 D-27), Start Over and Regenerate Thread need no code changes: deleting journal lines or writing new ThreadDone lines changes the stamps by themselves (RESEARCH Pattern 3, CR-B02 precedent).
Output: model fields, DiscoveryStaleness/CorpusDetector changes, unit + integration tests.
</objective>

<objective>
Close verification gap CR-01 at the provider/media layer and gap CR-02 in the keys screen.

Purpose: `ILlmProvider` promises "never throws for API/HTTP failures", but both providers and the media client rethrow every `OperationCanceledException`, including SDK/HttpClient 10-minute transport timeouts (`TaskCanceledException` with the caller token NOT cancelled). Those escape classification and end a generation run silently (SC3 / PROV-04). Separately, a key test that finishes after the user pressed Clear or edited the key writes the stale key back to the DPAPI store (01-07 truth "Clear removes a key", PROV-02).
Output: ct-filtered cancellation handling in `OpenAITextProvider`, `AnthropicTextProvider`, `OpenAIMediaClient`; a `KeyTestGuard` helper and hardened `StepApiConfiguration.TestKeyAsync`; regression tests.
</objective>

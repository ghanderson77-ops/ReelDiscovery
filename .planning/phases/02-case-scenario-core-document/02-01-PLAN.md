| Boundary | Description |
|----------|-------------|
| User scenario text -> CaseDraft | Untrusted free text (may contain real names, huge pastes) enters the model |
| case JSON text -> CaseDraft.FromJson | Future case.json/draft files (Phase 3) are parsed into the model |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | D (DoS / denial of wallet) | CaseDraft.ValidateScenario | mitigate | Hard 8,000-character cap checked before any LLM call; message tells the user the exact length |
| T-02-02 | T (Tampering) | CaseDraft.FromJson | mitigate | System.Text.Json with typed POCOs only (no polymorphic/type-name handling); null result throws InvalidOperationException |
| T-02-03 | I (Information disclosure) | CaseDraft serialization | accept | No secrets are stored on CaseDraft (API keys stay in the DPAPI store); scenario text is user-owned data |
| T-02-04 | T (Tampering) | Date fields | mitigate | Single TryParseExact("yyyy-MM-dd", InvariantCulture) helper; no culture-dependent parsing |
</threat_model>

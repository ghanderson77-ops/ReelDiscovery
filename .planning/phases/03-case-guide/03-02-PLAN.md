    `ClippingDetector.Find(Control root, ClippingOptions? options)`: walk all visible descendants and return human-readable findings `"{Path}: {problem} (bounds {w}x{h}, needs {pw}x{ph})"` where Path = names/types from root down (use `Name` when set, else `TypeName("text")`). Rules:
    1. `Label` with `AutoSize == false` and `AutoEllipsis == false` and non-empty text: measure with `TextRenderer.MeasureText(text, font, new Size(ClientSize.Width, int.MaxValue), TextFormatFlags.WordBreak | TextFormatFlags.NoPrefix)`; finding if measured height > `Height + 1` or (single-line text without spaces) width > `Width + 1`.
    2. `Label` with `AutoSize == true` and `MaximumSize.Width > 0`: finding if `PreferredSize.Height > Height + 1`.
    3. `ButtonBase` (incl. ThemedButton): finding if `PreferredSize.Width > Width + 1` or `PreferredSize.Height > Height + 1`.
    4. Any visible control (except children of a `ScrollableControl` with `AutoScroll == true`, and except `DataGridView`/`ListBox` internals) whose `Bounds` exceed `Parent.ClientRectangle` by more than 1 device px on the right or bottom: "extends past its parent".
    5. `ScrollableControl` with `AutoScroll == true` and `HorizontalScroll.Visible`: "horizontal scrollbar visible".
    6. `DataGridView` whose child `HScrollBar` is visible: "grid horizontal scrollbar" unless `options.AllowGridHorizontalScroll`.
    7. Skip controls whose `Name` is in `options.IgnoreNames`.
    Never throw from Find (wrap per-control checks; record "check failed: {message}").

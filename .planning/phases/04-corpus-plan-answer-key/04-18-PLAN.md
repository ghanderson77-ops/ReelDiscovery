| case.json/corpus-plan.json -> step | Untrusted persisted plan and approval state |
| User -> Approve | Writes files into the case folder |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-55 | Tampering | Approve file writes | mitigate | Paths = EnsureFolder(draft) + constant names (answer-key.csv/.xlsx, FileNameFor(folder name)); atomic temp+move writes; approval recorded only after all three succeed |
| T-04-56 | Elevation of Privilege | CSV/XLSX content | mitigate | Encoding delegated to AnswerKeyCsvWriter (OWASP guard) and AnswerKeyXlsxWriter (inline strings, no formulas) |
| T-04-57 | Tampering | Plan/case consistency | mitigate | corpus-plan.json written before case.json references the new PlanId; load requires matching PlanId |
| T-04-58 | Denial of Service | Long runs / closing | mitigate | Cancel Planning, Dispose cancels the token (no further billed calls), CancelAndWaitForRun with timeout |
| T-04-59 | Repudiation | Silent re-plan | mitigate | Stale guide never triggers a re-plan; banner + explicit Re-plan or Keep This Plan (D-25) |

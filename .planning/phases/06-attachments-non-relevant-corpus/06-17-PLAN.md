| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-50 | Denial of Service (cost) | Attachment retries | mitigate | Hard cap 3 attempts; refusals/timeouts not re-asked; invite warnings not retried |
| T-06-51 | Denial of Service (cost) | Media after auth/quota failure | mitigate | MediaRunGate stops all remaining media on the first Stopped result; 2 concurrent media calls max |
| T-06-52 | Elevation | Media failure ending the run | mitigate | The unit never calls SetFatal; only the text provider can stop the run (Decision 2) |
| T-06-53 | Tampering | Builder exceptions on hostile content | mitigate | Clamped content (06-11) and a catch that turns any build error into Failed for that attachment only |

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| case.json -> CaseDraft.Discovery | User-editable file; counts and ids untrusted |
| discovery-documents.json -> DiscoveryDocumentSet | Untrusted sidecar; may be oversized, corrupt, from a newer build, or tampered |
| sidecar FileName -> filesystem path | Name read back from disk becomes a path to write or shell-open |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering | DiscoverySettings.Normalize | mitigate | Clamp every count to its D-12..D-19 range, cap witnesses at 6, drop blank/duplicate ids |
| T-08-02 | Tampering/Elevation | DiscoveryStore.DocxPath | mitigate | Accept only IsDiscoveryFileName names; resolve with GetFullPath and require StartsWith(Discovery root) |
| T-08-03 | Denial of Service | DiscoveryStore.Load | mitigate | 20 MB size cap before read; catch JSON/IO exceptions; never throw |
| T-08-04 | Tampering | DiscoveryStore.Load | mitigate | Refuse newer FormatVersion; ignore a set whose CaseId differs |
| T-08-05 | Information disclosure | Staleness hashes | accept | SHA-256 used for change detection only; no secrets hashed |
</threat_model>

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-10-11 | Tampering | backup and sidecar paths | mitigate | Constant stem + invariant timestamp + counter, joined to the case folder; no name from file content (T-04-68, ASVS V12) |

| T-10-14 | Tampering | concurrent writers | mitigate | Per-case-folder SemaphoreSlim held across harvest, both writes and the sidecar save |
| T-10-15 | Spoofing | relabels for DocIDs of another plan | mitigate | PlanId from the per-file snapshot (or strict legacy match); DocID must exist in the plan (D-04, D-09) |

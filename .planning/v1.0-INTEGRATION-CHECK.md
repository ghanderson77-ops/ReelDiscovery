### Auth and run protection (desktop equivalents)

- **Stale-guide generation:** now PROTECTED. Entry: `GenerationUiText.EntryDecision` puts `HasPlan && GuideStale` ahead of approval (`GenerationUiText.cs:772`), which leads to the GuideChanged card. Run: `RunCoreAsync` refuses a stale or unapproved plan before the folder, resolver or gateway (`StepGenerateCorpus.Run.cs:444-465`). `new GenerationRunner(` exists only at `.Run.cs:565`. Every run button goes through `StartRunAsync` → `RunCoreAsync`: state card l.349, banner l.379, Continue l.374, Retry Failed l.384.
- **Legitimate runs are not blocked:** `IsGuideStale` is false when the hashes match or the current hash was kept (`CorpusApproval.cs:209-216`). After Keep This Plan, `ApproveAsync` is allowed (`StepReviewPlan.Run.cs:558`) and the run guard passes.
- **Approving a stale plan:** blocked twice, in `PlanNextGate(..., guideStale)` and in `ApproveAsync`.
- **Resolver in flight:** Back and Next are disabled (`StepGenerateCorpus.cs:139-140`). It counts as a run in `WizardForm.cs:544`, so close waits with `CancelAndWaitForRun` and `_stopAfterResolve`.
- **Unprotected:** nothing new. N1 (the Case Guide banner skips guide validation) is a validation bypass, not a paid-run bypass.

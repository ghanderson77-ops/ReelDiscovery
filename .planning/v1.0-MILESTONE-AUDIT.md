## Milestone definition of done

ROADMAP v1.0 has 8 phases. Phase 1 builds the foundation and gateway. Phase 2 adds the scenario and core document, Phase 3 the case guide, and Phase 4 the corpus plan and answer key. Phase 5 writes relevant evidence and the narrative ledger. Phase 6 adds attachments and the non-relevant corpus. Phase 7 covers scale, cost, QA and the cutover, and Phase 8 adds ancillary discovery documents. Every roadmap success criterion is verified in code and tests (Phase 1 5/5, Phase 2 5/5, Phase 3 4/4, Phase 4 5/5, Phase 5 5/5, Phase 6 6/6 with one override, Phase 7 5/5, Phase 8 3/3). What is missing is human or live-provider confirmation for phases 1, 2, 7 and 8.

The core value is that every relevant email stays faithful to one case story. Knowledge gating, the narrative ledger, canonical-value validation and the end-of-run timeline and value scans implement it, and all of them are wired (CORP-01..11, QA-03). Phase 5's live UAT confirmed it on one live run. The open risk to it is W1: generation can run against a guide that was edited after the plan was approved.
